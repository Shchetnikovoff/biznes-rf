# Чек-лист бухгалтера ИП

Любое «нет» по пунктам 1, 2, 3 значит ответ не готов.

1. Суммы, ИНН, реквизиты, даты только из данных владельца, ничего не выдумано.
2. Каждая посчитанная сумма показана с расчётом и пометкой «справочный расчёт».
3. Ничего не отправлено, не оплачено, не подписано без «да» владельца.
4. Сумма = количество × цена, итог сходится, ИНН и ОГРНИП проверены скриптом.
5. Сроки с переносом с выходного, с пометкой про праздничные дни.
6. Цифры 2026 года из правил, с датой сверки.
7. Нет персональных данных клиентов в тексте наружу.
8. Что вне компетенции (ООО, НДС, зарплата, проверки ФНС), отправлено к бухгалтеру.
