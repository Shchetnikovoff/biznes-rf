# Бизнес РФ

Готовые помощники для малого бизнеса в России внутри Claude: КП, заявки,
почта, должники, звонки, прогноз денег, посты, отзывы, найм, договоры.
Работают по-русски, в рублях, по российским правилам. Ничего не отправляют,
не публикуют и не оплачивают без вашего «да».

## Как поставить

1. Приложение Claude → Customize → Plugins → Add → Add marketplace → Add from a repository.
2. Вставьте `https://github.com/Shchetnikovoff/biznes-rf` и нажмите Sync.
3. В открывшемся каталоге, вкладка Code, у «Бизнес РФ» нажмите «+».
4. На Windows сначала установите Git for Windows, без него каталог плагинов
   не открывается.

## Обязательно: одна строка в AGENTS.md

Если в вашей папке есть AGENTS.md со своими правилами, агент часто решает задачу
сам и помощника не зовёт. Допишите в конец AGENTS.md:

```
## Навыки
Любая задача по бизнесу (с чего начать, КП, заявка клиента, должники, звонки, деньги и прогноз, посты, отзывы, вакансия, договор): сначала запусти подходящий навык плагина «Бизнес РФ», и только потом смотри файлы. Не знаешь какой: запусти smb-router.
```

Или попросите агента: «допиши в AGENTS.md раздел про навыки Бизнес РФ из README плагина».

## Как пользоваться

Пишите обычными словами, называть помощника не нужно:

| Фраза | Помощник |
|---|---|
| «С чего начать?» | smb-router |
| «Сделай КП для…» | proposal-builder |
| «Пришла заявка, вот текст…» | speed-to-lead |
| «Разбери почту за неделю» | inbox-manager |
| «Кто мне должен?» | invoice-chase |
| «Оцени заявки из таблицы» | lead-triage |
| «Кому позвонить сегодня?» | call-list |
| «Сводка на неделю» | monday-brief |
| «Хватит ли денег на три месяца?» | cash-flow-snapshot |
| «Напиши пост для канала» | social-content-engine |
| «Что продвигать в этом месяце?» | content-strategy |
| «Ответь на отзыв» | review-reputation |
| «Напиши вакансию» | job-post-builder |
| «Разбери резюме» | hiring-screener |
| «Проверь договор» | contract-review |
| «Я делаю это каждую неделю, собери помощника» | build-agent |

Не сработало по фразе: напишите «запусти proposal-builder» (или имя нужного
помощника).

## Другие роли в этом же каталоге

В том же репозитории лежит плагин «Копирайтер» (посты, письма, тексты для сайта и Авито, правка, голос бренда). Ставится тем же путём: после Sync в каталоге у «Копирайтер» нажмите «+». Начните с фразы «с чего начать с текстами».

В том же каталоге «Бухгалтер ИП» (счета и акты, аванс УСН, сроки, должники, проверка ИНН и ОГРНИП). Считает скриптами, ничего не отправляет и не платит без вашего «да». Работает для ИП; ООО, НДС и зарплата не берёт. Начните с фразы «с чего начать с учётом». Скрипты требуют Python на компьютере: без него навыки считают пошагово, но медленнее.
