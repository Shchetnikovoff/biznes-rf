# Должники (ИП)

Прочитай `../../shared/pravila-buhgaltera.md`. Отвечай по-русски, на «Вы», коротко.

1. Источник: `buh/journal.csv` (выставленные счета и оплаты) и `buh/payments.yaml`. Нет файлов: попроси владельца вставить список «клиент, номер счёта, сумма, дата счёта, срок оплаты, оплачено или нет».
2. Составь список неоплаченных: клиент, счёт, сумма, срок, дней просрочки (считай по календарю, скриптом или построчно). Сверху самые старые.
3. Для каждого предложи следующий шаг по нарастающей:
   - до 7 дней просрочки: мягкое напоминание;
   - 7 до 30 дней: твёрдое напоминание с новым сроком;
   - больше 30 дней: претензия.
4. Претензия: сумма долга, основание (договор, счёт, акт), срок оплаты 30 календарных дней (ч. 5 ст. 4 АПК РФ, если договор не даёт иной срок), проценты по ст. 395 ГК РФ по ключевой ставке ЦБ (перед отправкой сверить ставку на cbr.ru), предупреждение о суде. Без угроз и оскорблений.
5. Покажи тексты. Отправляет владелец сам, только после «да». Данные клиента в текст берём только из файлов владельца.
