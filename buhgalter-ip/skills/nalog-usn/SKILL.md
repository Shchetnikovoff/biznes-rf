# Налог УСН для ИП

Прочитай `../../shared/pravila-buhgaltera.md`. Отвечай по-русски, коротко.

## Что нужно
1. Режим из `buh/profile.yaml` (УСН 6%, УСН 15%, патент, НПД). Нет: спроси.
2. Доходы по кварталам из `buh/journal.csv` (поступившие деньги, тип «доход»). Нет данных: попроси владельца назвать суммы по кварталам. Не выдумывай.
3. Есть ли работники (от этого зависит предел вычета: без работников до 100%, с работниками до 50%).
4. Взносы за себя: фиксированные 57 390 руб. за 2026, плюс 1% с дохода свыше 300 000 руб. (считается сам, максимум 321 818 руб.).

## Как считать (УСН «доходы» 6%)
Аванс за период = доходы с начала года × 6% минус вычет взносами минус авансы, уже начисленные раньше. Запусти:
```
python скрипт usn_calc.py данные.json
```
(файл `scripts/usn_calc.py` в этом навыке; вход: `{"rate":6,"quarters":[к1,к2,к3,к4],"fixed_contrib":57390,"employees":false}`). Нет Python: считай пошагово вручную и покажи каждую строку.
Покажи таблицу: период, доход нарастающим, налог, вычет, к уплате. К таблице добавь: срок уплаты (см. навык `sroki`) и фразу «Справочный расчёт, сверьте с бухгалтером или личным кабинетом ФНС».

## Уточни у владельца, если сомнение
- Взносы в вычет идут в тот год, за который они начислены; уменьшить аванс можно и на взносы, срок которых ещё не наступил (по разъяснению 1С, не письмо ФНС): скажи, что это пункт для сверки с бухгалтером.
- УСН 15%: минимальный налог 1% от доходов, если обычный налог меньше; расходы только из закрытого перечня ст. 346.16 НК РФ. Такой расчёт делай только если владелец дал все расходы, иначе предложи бухгалтера.
- НПД: 4% и 6% с каждого поступления, чек обязателен, лимит 2,4 млн руб.
- Патент: налог фиксированный, срок по патенту.
