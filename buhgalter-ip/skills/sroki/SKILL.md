# Сроки ИП

Прочитай `../../shared/pravila-buhgaltera.md`. Отвечай по-русски, коротко.

1. Режим и наличие работников возьми из `buh/profile.yaml`. Нет: спроси.
2. Построй календарь скриптом `scripts/deadlines.py` (даты с переносом с выходного на понедельник):
```
python deadlines.py 2026-10-01 2027-04-30
```
(добавь `--employees`, если есть работники). Нет Python: возьми даты из правил (УСН: авансы 28.04, 28.07, 28.10; налог ИП за год 28.04; декларация ИП за год 25.04; взносы фиксированные 28.12; 1% до 01.07; уведомление об авансе до 25 числа) и сам сдвинь выходные.
3. Покажи ближайшие 6 сроков: дата, день недели, что сделать.
4. В конце: «Праздничные дни не учтены, сверьте с производственным календарём на consultant.ru. Цифры и сроки сверены 29.09.2026, перед платежом проверьте на nalog.gov.ru».

Для НПД срок один: до 28 числа следующего месяца, чек при каждой оплате. Для патента срок указан в патенте.
