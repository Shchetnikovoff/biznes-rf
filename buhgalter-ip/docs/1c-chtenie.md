# Как подключить 1С только на чтение (для админа 1С)

Этот шаг делает администратор 1С или программист, не владелец и не ученик. Без него плагин работает по журналу `buh/journal.csv` и файлам.

## Что нужно
1. В 1С опубликован OData для нужных объектов (только чтение нужных справочников и регистров, не всё).
2. Отдельный пользователь 1С с ролью «только чтение» на эти объекты. Не администратор, не тот, под кем работает бухгалтер.
3. Тестовая копия базы для первых проб.

## Готовый мост
Открытый проект `1c-odata-mcp` (github.com/evilbruce666/1c-odata-mcp, лицензия MIT). По умолчанию только чтение, запись включается отдельными флагами: не включайте. Запуск: `npx -y 1c-odata-mcp` с адресом базы и логином/паролем в переменных окружения, не в чате.

## Правила безопасности
- Пароль хранить только в переменных окружения или менеджере паролей, в чат и файлы проекта не вставлять.
- Персональные данные (ФИО контрагентов, физлиц) из 1С в модель не выгружать: модель работает вне России. Выгружайте суммы, даты, номера документов, условные названия.
- Запись в 1С через агента не включать. Документы создаёт человек.
- Перед подключением к рабочей базе прогнать на тестовой копии.

## Что не проверено
Плагин не подключён к реальной 1С, только описан порядок. Проверка на выдуманной тестовой базе остаётся открытой.
