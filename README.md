# Бизнес РФ

Готовые помощники для малого бизнеса в России внутри Claude: КП, заявки,
почта, должники, звонки, прогноз денег, посты, отзывы, найм, договоры.
Работают по-русски, в рублях, по российским правилам. Ничего не отправляют,
не публикуют и не оплачивают без вашего «да».

## Как поставить

1. Приложение Claude → Customize → Plugins → «+» → Add from a repository.
2. Вставьте адрес этого репозитория и нажмите Sync.
3. Вкладка Code → «Бизнес РФ» → «+».
4. На Windows сначала установите Git for Windows, без него каталог плагинов
   не открывается.

## Как пользоваться

Пишите обычными словами, называть помощника не нужно:

| Фраза | Помощник |
|---|---|
| «С чего начать?» | smb-router |
| «Сделай КП для…» | proposal-builder |
| «Пришла заявка, вот текст…» | speed-to-lead |
| «Разбери почту за неделю» | inbox-manager |
| «Кто мне должен?» | invoice-chase |
| «Оцени заявки из таблицы» | lead-triage |
| «Кому позвонить сегодня?» | call-list |
| «Сводка на неделю» | monday-brief |
| «Хватит ли денег на три месяца?» | cash-flow-snapshot |
| «Напиши пост для канала» | social-content-engine |
| «Что продвигать в этом месяце?» | content-strategy |
| «Ответь на отзыв» | review-reputation |
| «Напиши вакансию» | job-post-builder |
| «Разбери резюме» | hiring-screener |
| «Проверь договор» | contract-review |
| «Я делаю это каждую неделю, собери помощника» | build-agent |

Не сработало по фразе: напишите «запусти proposal-builder» (или имя нужного
помощника).
